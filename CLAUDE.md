# BearlessNotes — video-bookmark-app

Особистий кросплатформний буркмарк-менеджер для збереження посилань на
YouTube/TikTok відео з прев'ю, ієрархічними тегами та статусами перегляду.

## Технічне завдання

### 1. Загальна ідея
Особистий буркмарк-менеджер для збереження посилань на YouTube і TikTok
відео з прев'ю, тегами та статусами перегляду. Платформи: iOS, Android,
веб. Перша версія — для власного використання, без монетизації.

### 2. Зберігання даних, синхронізація, акаунт
Офлайн-перший підхід: посилання завжди зберігаються локально на пристрої,
застосунок повністю працює без інтернету і без акаунту. Хмарна база даних
(Firebase або Supabase) для синхронізації між iOS/Android/веб, коли акаунт
підключено. Вхід через Google акаунт. Синхронізація автоматична у фоні. У
налаштуваннях — час останньої синхронізації і кнопка вийти.

### 3. Додавання відео
Через кнопку "поділитися" з YouTube/TikTok (Android/iOS share-intent —
застосунок зʼявляється у системному меню "Поділитися", посилання
автоматично підставляється у форму додавання), або вручну кнопкою
"плюс". Прев'ю, назва, тривалість підтягуються автоматично за
посиланням (реальний oEmbed-запит до YouTube/TikTok). Одразу можна
обрати статус і теги.

### 4. Теги
Ієрархічна структура за прикладом Bear (вкладені теги через слаш),
максимум 10 рівнів вкладеності. Одному відео — декілька тегів. У кожного
тега — власна кругла іконка-бейдж і колір (обирається при створенні або
пізніше в редакторі тегів; колір з палітри — єдине місце в інтерфейсі, де
дозволений яскравий/помаранчевий колір, оскільки це контент тега, а не
елемент керування). Розділ "Невідсортоване" (відео без жодного тега) —
завжди першим рядком у панелі тегів. Окремого розділу "Inbox" немає (у
нього не було чіткого визначеного сенсу, прибрано). При видаленні тега —
запит: видалити пов'язані відео чи перенести їх у невідсортоване.
Перейменування, зміна іконки/кольору і зміна батьківської папки тега —
через довге натискання на тег (див. пункт 7).

### 5. Статуси перегляду
"Планую подивитись", "Переглянуто" (можливий третій статус пізніше).

### 6. Головний екран
Два режими відображення стрічки, перемикаються кнопкою у шапці екрана:
- **Плитка (грід)** — картки на всю ширину. Кожна картка: прев'ю-зображення
  16:9 (іконка плей по центру, тривалість у правому нижньому куті), під
  зображенням назва відео жирним шрифтом, нижче теги-пігулки.
- **Список (компакт)** — те саме прев'ю зменшене і зліва, назва та теги
  справа від нього, в рядок.

Зверху фільтр-пігулки статусу (Усі / Планую / Переглянуто) і кнопка
перемикання грід/список. Якщо активний фільтр за тегами — під пігулками
з'являється чіп "Фільтр: <назви тегів>" з кнопкою очищення.

Довге натискання на картку вмикає режим множинного вибору: замість
плаваючого острівця знизу з'являється панель дій (Скасувати / "Обрано: N"
/ "Додати тег"), яка відкриває панель тегів і додає обрані теги до всіх
позначених відео одночасно (не замінюючи вже наявні).

Знизу, коли немає активного вибору — плаваючий острівець-капсула по
центру (не на всю ширину, з легкою прозорістю) з 3 круглими кнопками:
пошук, плюс (акцентна кнопка додавання відео), налаштування. Окремо, біля
лівого краю екрана навпроти острівця — маленький "язичок" фільтрів
(власна напівпрозора капсула з таким самим заокругленням, як в острівця):
відкриває панель тегів (пункт 7) тапом або свайпом управо; головний
екран при цьому лишається видимим, розмитим на задньому фоні.

Кольорова схема — світла (One UI Samsung, 8.5–9): біле/світло-сіре тло,
великі заокруглення, сірі (не яскраво-помаранчеві) елементи керування й
виділення активних станів. Помаранчевий колір в інтерфейсі присутній
лише як вміст — колір конкретних тегів, ніде в елементах керування
(кнопках, пігулках, чекбоксах, острівці, язичку).

### 7. Панель тегів
Одна об'єднана висувна панель зліва — і для перегляду/фільтрації, і для
редагування дерева тегів (замість двох окремих екранів). Зверху —
перемикач "Фільтр" / "Редагування" (за замовчуванням "Фільтр") і рядок
пошуку по тегах.

Список: рядок "Невідсортоване" з лічильником, далі теги — батьківські з
кількістю відео та стрілочкою розгортання підтегів, вкладені підтеги з
відступом зліва (іконки-бейджі підтегів того самого розміру, що й у
батьківських тегів). Кожен розкритий тег разом зі своїми підтегами
візуально групується в окрему білу картку-острівець із заокругленими
кутами: якщо картка перша в списку — заокруглення тільки знизу, якщо
остання — тільки згори, якщо посередині — і згори, і знизу.

Звичайний тап на тег завжди перемикає його вибір для фільтра (чекбокс
ліворуч від лічильника відео; чекбокс сірий, як кнопка "+" на острівці,
не помаранчевий) — незалежно від того, в якому режимі перемикач. Обрані
теги збираються в чіпи над нижньою кнопкою "Показати N відео". Множинний
вибір тегів підтримується завжди.

Довге натискання на тег перемикає верхній перемикач на "Редагування" і
відкриває інлайн-меню прямо під цим тегом з трьома пунктами:
- **Перейменувати** — відкриває редактор тега (пункт 11), де також можна
  змінити іконку й колір.
- **Материнська папка** — окремий екран вибору нового батьківського тега
  зі списку всіх інших тегів (з повним шляхом) або "Без батьківського
  тега"; тег і всі його нащадки виключені зі списку, щоб уникнути циклів.
- **Видалити** — після підтвердження запитує, видалити пов'язані відео чи
  перенести їх у невідсортоване.

Внизу списку — кнопка "+ Новий тег" (сірого кольору тексту/іконки).
Нижня кнопка підтвердження за замовчуванням — "Показати N відео"
(кількість відео, що відповідають обраним тегам); у контекстах вибору
тегів для відео чи налаштувань замінюється на "Готово" відповідним
екраном, що відкрив панель.

### 8. Форма додавання відео
Зверху "Скасувати" / "Нове відео" / "Зберегти". Поле вставки посилання
(автоматично заповнене, якщо екран відкрито через "Поділитися"). Картка з
автопідтягнутим прев'ю, назвою, тривалістю. Вибір статусу — дві
пігулки-перемикача в ряд. Теги — одна кнопка-селектор (показує обрані
назви тегів або "Обрати теги"), яка відкриває об'єднану панель тегів
(пункт 7) з можливістю одразу створити новий тег.

### 9. Вкладка перегляду відео
Зверху назад / "Відео" / іконка зовнішнього посилання (перехід у
YouTube/TikTok). Плеєр 16:9 з кнопкою плей по центру. Нижче — назва відео
в редагованому полі з окремою кнопкою "Зберегти" (активна, лише якщо
текст змінено), перемикач статусу (дві пігулки), обрані теги з кнопкою
"Додати тег" (відкриває панель тегів із вже позначеними тегами цього
відео — тап одразу застосовує чи знімає тег), невелике текстове поле
коментаря з окремою кнопкою "Зберегти" під ним (коментар і назва
зберігаються тільки по натисканню "Зберегти", а не на кожне натискання
клавіші). Дві опції поведінки при натисканні на відео зі стрічки
(обирається в налаштуваннях): перехід одразу в YouTube/TikTok, або
відкриття цієї вкладки.

### 10. Налаштування
Блок акаунту Google (іконка, email, час синхронізації, кнопка "Вийти").
Перемикач теми — 3 сегменти (Світла/Системна/Темна). Перемикач способу
відкриття відео (У застосунку/YouTube-TikTok) — 2 сегменти. Пункт
"Редагувати теги" відкриває ту саму об'єднану панель тегів (пункт 7) в
режимі "Редагування" — окремого екрана керування тегами немає. Пункт
"Невідсортоване" (лічильник відео).

### 11. Редактор тега
Зверху "Скасувати" / "Редагувати тег" (або "Новий тег") / "Готово".
Велика кругла іконка-бейдж тега (коло, кольоровий фон — у стилі One UI,
не квадрат) поруч із полем назви. Під час введення назви **нового** тега
(не редагування наявного) під полем зʼявляється випадаючий список
підказок — наявні теги, назва яких містить уже введений текст останнього
сегмента шляху; вибір підказки підставляє її замість цього сегмента.
Нижче — сітка іконок 6 в ряд для вибору іконки тега. Ще нижче — ряд
кольорових кружечків для вибору кольору тега.

### 12. Технології
React Native + Expo для крос-платформності (iOS, Android, веб одним
кодом). Share-intent (отримання посилань через системне "Поділитися")
реалізовано через `expo-share-intent`; на вебі та в Expo Go ця
функціональність не активна і не потрібна для тестування — лише в
dev/production-білді.

### 13. Дизайн-система (One UI)
Візуальний стиль орієнтований на Samsung One UI 8.5–9: суцільно
світле/біле тло, великі радіуси заокруглення, кольорові круглі іконки-
бейджі для тегів, м'які тіні замість контрастних меж. Акцентний
(яскраво-помаранчевий) колір використовується виключно як контент —
колір конкретного тега з палітри; в жодному елементі керування
інтерфейсу (кнопках, пігулках, чекбоксах, плаваючому острівці, язичку
фільтрів, перемикачах) яскравих акцентних кольорів немає — активний/
виділений стан позначається нейтральним сірим. Плаваючий острівець і
язичок фільтрів — з легкою прозорістю; при відкритті панелі тегів
головний екран лишається видимим, розмитим на задньому фоні.

### 14. Етапи роботи
1. Технічне завдання і ескізи — готово.
2. Розробка застосунку покроково з тестуванням.
3. Тестування автором.
4. Публікація для iOS/Android/веб.
5. Монетизація — пізніше, за бажанням.

## Архітектурні рішення

- **Expo SDK 54 + TypeScript**, навігація через **Expo Router** (file-based,
  однаково працює на iOS/Android/web).
- **`metro.config.js`**: вимикає `resolver.unstable_enablePackageExports`
  (Metro за замовчуванням у SDK 54 резолвить ESM-збірку деяких пакетів,
  напр. `zustand`, для веб-платформи замість CJS/react-native — це ламає
  статичний веб-експорт через `import.meta`, якого немає в class-скриптах).
- **Офлайн-перший стан**: `zustand` зі збереженням у
  `AsyncStorage` (`@react-native-async-storage/async-storage`) —
  єдине джерело правди локально; хмарна синхронізація (Firebase/Supabase)
  підключається пізніше як окремий шар над тим самим стором, не змінюючи
  публічний API стору.
- **Іконки**: `@expo/vector-icons` (Ionicons).
- Стилі — `StyleSheet.create`, без сторонніх CSS-фреймворків, щоб
  мінімізувати залежності на старті.
- Дані відео (прев'ю/назва/тривалість) отримуються реальним oEmbed-
  запитом до YouTube/TikTok через сервіс `services/videoMeta.ts`.
- **Share-intent**: `expo-share-intent` + конфіг-плагін в `app.json`
  (Android intent-filter на `text/*`). `RootLayout` обгорнутий у
  `ShareIntentProvider`; отримане посилання перенаправляється на
  `/add-video?sharedUrl=...`, звідки попередньо заповнює поле URL. Не
  працює в Expo Go — потребує dev/production-білд.
- **Дизайн**: One UI (Samsung) світла тема — див. пункт 13 ТЗ. Токени
  кольорів/радіусів/відступів — у `constants/theme.ts`.

## Структура проєкту

```
app/                      Expo Router екрани
  _layout.tsx             Кореневий layout (провайдер стору, ShareIntentProvider, тема)
  index.tsx               Головний екран (стрічка відео, грід/список, множинний вибір)
  add-video.tsx           Модальний екран додавання відео (приймає ?sharedUrl=)
  video/[id].tsx          Перегляд відео (редагована назва, теги, коментар)
  settings.tsx            Налаштування (панель тегів у режимі "Редагування")
  tag-editor.tsx          Редактор тега (назва, іконка, колір, автопідказки)
  tag-reparent.tsx        Модальний екран вибору нової батьківської папки тега
components/
  VideoCard.tsx           Картка відео (грід/список, стан вибору)
  FilterPills.tsx         Пігулки-фільтри статусу
  SearchBar.tsx           Рядок пошуку (автофокус, кнопка очищення)
  FloatingIsland.tsx      Плаваючий острівець-капсула з 3 кнопками (пошук/плюс/налаштування)
  FilterTab.tsx           Окремий язичок-капсула зліва, відкриває панель тегів
  TagChip.tsx             Пігулка тега
  TagsDrawer.tsx          Об'єднана панель тегів: фільтр + інлайн-редагування
  StatusToggle.tsx        Перемикач статусу (дві пігулки)
store/
  useLibraryStore.ts      Zustand-стор: відео, теги, фільтри, налаштування
types/
  index.ts                Video, Tag, WatchStatus, Settings
constants/
  theme.ts                Кольори (One UI, світла тема), розміри, типографіка
services/
  videoMeta.ts            Отримання прев'ю/назви/тривалості через oEmbed
```

## Команди

```
npm install
npm run start     # Expo dev server (вибір платформи: i/a/w)
npm run web       # запуск веб-версії
npm run ios
npm run android
```
