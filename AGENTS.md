# mindEva (репозиторій BearlessNotes) — інструкція для Codex

Застосунок для нотаток і «простору для мислення»: Expo / React Native (Android + браузер + Mac-оболонка Electron) і Firebase.
Це продовження роботи, яку вів Claude Code. **Весь контекст і історія рішень — у `CLAUDE.md`** (англійською, довгий; прочитай
його перед першою зміною). Нижче — те, що не можна порушити. Повний бриф продукту — `PROJECT_BRIEF.md`, етапи — `DEVELOPMENT_PLAN.md`,
налаштування поза кодом — `docs/services-and-settings.md`, стан переходу й відкат — `docs/CODEX_HANDOFF.md`.

- Українською, коротко, простими словами, по одному питанню за раз. Користувач часто слухає відповіді як аудіо: зв'язний текст, не таблиці.

## Золоті правила (кожне колись зламало реальну поставку)
1. **Нічого не додавати в `package.json` → `scripts`.** Вони входять у «відбиток» (`runtimeVersion` = політика `fingerprint`); один рядок
   відрізав телефон від усіх OTA-оновлень. Нові скрипти — лише файлами в `scripts/` (shell/python/mjs).
2. **Нова залежність, зміна `plugins/`, `modules/`, `app.json` = новий APK**, OTA її не доставить. Перед публікацією OTA звіряй відбиток:
   `npx @expo/fingerprint fingerprint:generate --platform android` має дорівнювати відбитку встановленої збірки.
   Кореневий `.gitignore` теж міг входити у відбиток (у сусідніх проєктах так) — не чіпати без потреби.
3. **Firestore: правила «тільки власник» уже розгорнуті.** Кожен список-запит обов'язково з умовою `ownerId` (використовуй `ownedQuery`),
   кожен `onSnapshot` — з обробником помилок, інакше відмова бази валить застосунок.
4. **Веб-збірка — лише `sh scripts/build-web.sh` у `web-build/`.** Ніколи не голий `expo export` і не в `dist/` (його перезаписує `eas update`
   з порожніми `EXPO_PUBLIC_*`). Після веб-збірки закрити всі вкладки застосунку й відкрити одну свіжу. Роздавати: `scratchpad/serve.py 8899 web-build`
   (порт 8081 або 8899 — інші Google не пустить). Mac-застосунок: `sh scripts/build-mac.sh`.
5. **Швидкодія — частина готовності.** Перед передачею нового екрана/списку/вікна виміряй на телефоні (`mindeva://perf?on=1`, `adb logcat -s ReactNativeJS`,
   `[perf]`): від дотику до першого кадру — до ~50 мс блокування JS-потоку. Вікно не тримати змонтованим закритим (`utils/closedCostsNothing`),
   рядки списків через `memo`/`memoLatest`, важкі картки — після `useSlideSettled`, списки лише `FlatList`, іконки — шрифт `assets/fonts/lucide.ttf`
   (`lucideGlyphs.ts`), не нові SVG.
6. **Не додавати інструменти для самого планувальника «розробка»** (користувач зупинив цю петлю 2026-10-30).
7. Дрібне: `git restore package-lock.json` перед `git pull`, якщо лок-файл розійшовся між macOS і Linux; нові рядки інтерфейсу — українською.

## Збірка й оновлення (перевір команди перед першим запуском — див. HANDOFF)
- Розробка: `npm install`, `npm start` (є `expo-dev-client`: Expo Go не підійде, потрібна dev/preview-збірка на телефоні).
- Перевірка типів перед публікацією: `NODE_OPTIONS=--max-old-space-size=8192 npx tsc --noEmit` (не склеювати з публікацією через `;`).
- OTA (лише JS): гілка `preview`. За аналогією з сусідніми проєктами:
  `eas update --branch preview --environment preview --platform android --message "…" --non-interactive`, потім 2–3 рази перезапустити застосунок.
- Новий APK (локально, бо хмарний ліміт безкоштовного плану вичерпано): `eas build --local --profile preview --platform android --output <шлях>.apk`.
  Потрібні Java 17 (`openjdk@17`) і Android SDK `/opt/homebrew/share/android-commandlinetools`; змінні середовища — у `~/.zprofile`.
  Готовий APK — у `scratchpad/apk/` (ця тека в `.gitignore`, у GitHub її НЕМАЄ).
- Установка на телефон не повинна стирати дані: той самий пакет і той самий підпис (ключ тримає EAS), застосунок НЕ видаляти перед установкою.
- Нотатки/справи/теги лежать у Firestore і переживають перевстановлення; не переживають локальні файли/фото, що ще не на Google Диску.

## Будова
- `App.tsx` / `App.web.tsx` — вхід (телефон / браузер); браузерна збірка = весь застосунок, відмінності — у `.web`-файлах-сусідах.
- `src/`: `AppNavigator.tsx`, `screens/`, `components/`, `hooks/`, `utils/`, `theme/`, `widgets/`, `notifications/`, `firestore*.ts`, `firebase*.ts`, `types.ts`, `features.ts`.
- `modules/`, `plugins/` — власний нативний код і Expo-плагіни (їхня зміна = новий APK). `desktop/` — оболонка Electron для Mac.
- `scripts/`: `build-web.sh`, `build-mac.sh`, `test-structure.sh`, `dev-board.py`, аудити.
- Редактор документів — власний блоковий (gesture-handler + reanimated v4, без сторонніх бібліотек списків); Полотно, Провідник, Інбокс «Думки», Карта, бази.
