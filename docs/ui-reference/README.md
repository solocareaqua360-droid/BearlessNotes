# Довідник інтерфейсу

Знімки справжніх екранів mindEva з телефона (зовнішній екран Fold, 475×751 dp, половинний розмір).
Дивитися перед тим, як малювати або будувати новий екран, щоб нове виглядало як решта застосунку.
Оновлювати, коли телефон підключений і екран помітно змінився.

Головне, що видно на знімках:
- Внизу док: зліва капсула (столи, пошук), праворуч «+» (48) і кругла кнопка «назад» / багатозадачність (48),
  12 між ними, 20 від краю.
- Зверху лише плашка з назвою, без кнопки «назад».
