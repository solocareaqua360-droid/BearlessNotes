# Застосунок для звичок: специфікація v0 (2026-11-20)

Окремий малий застосунок (не частина mindEva). Ціль: відмітка за 3 секунди, красиво, без ліній-сітки й «ланцюжків провини».

## П'ять видів звичок
| Вид | Приклад | Як відмічаєш | Що рахує |
|---|---|---|---|
| Лічильник до цілі | вода | тап «+0,25 / +0,5 л» | сума за день до цілі |
| Прийом із запасом | вітаміни | «Прийняв» | таблетки в пачці, дата «коли докупити», примітка («після їжі») |
| Тривалість | читання, ходьба, шахи, теорія музики | тап «+10 хв» або таймер | хвилини за день до цілі |
| Так / ні | вечірня оптимізація | один тап | виконано чи ні |
| Підходи й повтори | підтягування, присідання | «+ підхід», кроки +/- | підходи × повтори, план проти факту |

## Екрани
1. **Сьогодні**: усі звички дня картками, зверху смужка тижня; кожна картка має свою швидку дію.
2. **Звичка**: календар місяця з крапками, «27 з 30», м'яка серія, 4 тижні стовпчиками.
3. **Підходи**: план (3×8), підходи зі степерами, «повторити як минулого разу», графік по тижнях.
4. **Вітаміни**: розклад, залишок у пачці, коли докупити, історія, примітки.
5. **Віджети** (Android): вода (+0,25/+0,5), «прийняв» для вітамінів, ряд із 4 звичок.

## Правила
- Відмітка скасовується одним тапом (undo-смужка 5 с); можна відмітити вчора.
- Графік гнучкий: щодня / N разів на тиждень / певні дні; пауза (відпустка, хвороба) не ламає статистику.
- Прогрес м'який: «27 з 30», а не ланцюжок, що рветься від одного пропуску.
- Сповіщення з кнопкою «Зроблено» без відкриття застосунку.
- Ходьба: кроки з Health Connect (без тапів), за згодою.
- Вітаміни/ліки: позначка «вже прийнято сьогодні» (запобіжник від подвійної дози; не медична порада).
- Дані локально на пристрої; приватні (здоров'я). Зв'язок із mindEva мінімальний: посилання в обидва боки, рядок «виконано 4 з 5» у дні календаря.

## Порядок збірки
1. Лічильник + тривалість + віджет води → 2. Календар із крапками → 3. Вітаміни із запасом → 4. Підходи й повтори → 5. Сповіщення, Health Connect.
