# Сервіси й налаштування mindEva

Журнал усього, що налаштовано поза кодом: у консолях сервісів, на телефоні, на Mac.
Для кожного запису: **що**, **де**, **навіщо**, **коли**. Нове дописується одразу, в ту ж розмову,
де щось клацнули. Позначка «уточнити» означає, що точних даних у записах немає.

---

## Firebase — база й вхід

- **Що:** окремий проєкт `bearless-notes`, лише для mindEva (не спільний з іншими застосунками).
- **Де:** console.firebase.google.com → проєкт bearless-notes.
- **Тариф:** Spark (безкоштовний). Функції на сервері (Cloud Functions) потребуватимуть Blaze (оплата за фактом).
- **Що в ньому:**
  - Firestore, регіон `eur3` (Європа) — усі нотатки, справи, папки, дошки.
  - Authentication — вхід через Google.
  - Правила безпеки «тільки власник» — **розгорнуто 2026-09-15**. Навіщо: кожен бачить і змінює лише своє.
    Наслідок: кожен список у коді мусить мати умову «мій ownerId», інакше база відмовить.
  - Складені індекси Firestore — створювались, коли екран показував «порожньо» через відмову бази
    (запит «мій ownerId + проміжок дат»). Навіщо: без індексу такий запит не виконується.
- **Ключі:** у файлі `.env` на Mac (у git не потрапляє).

## Вхід через Google і Google Диск

- **Що:** вхід через Google + резервні копії фото й файлів на Google Диск.
- **Де:** Google Cloud Console, два різні проєкти:
  - проєкт Firebase (номер 499342524449) — його OAuth-клієнт робить вхід;
  - інший проєкт — у ньому Диск.
- **Дозволені адреси (Authorized JavaScript origins):** `http://localhost:8081` і `http://localhost:8899`.
  Навіщо: Google видає доступ до Диска лише знайомим адресам. Mac-застосунок працює саме на 8899.
- **Наслідок:** у браузері й на Mac раз на годину треба натискати «Підключити Диск». Це не баг:
  так влаштовано, бо Диск в іншому проєкті. Рішення про перенесення файлів у Firebase Storage
  **відкладене** (Storage потребує тарифу Blaze).

## Expo / EAS — збірки й оновлення

- **Що:** окремий проєкт Expo `bearless-notes` (не той, де лежать збірки застосунку відеозакладок).
- **Де:** expo.dev → проєкт bearless-notes.
- **Ідентифікатор застосунку Android:** `com.bearlessnotes.notes`. Змінювати не можна: після публікації в Play це назавжди.
- **Оновлення без перевстановлення (OTA):** гілка `preview`. Застосунок качає оновлення на першому запуску,
  а вмикає на наступному.
- **Збірки APK:** робляться локально на Mac (`eas build --local`), бо безкоштовний план має ліміт хмарних збірок на місяць.
- **Правило:** нічого не додавати в `scripts` файлу `package.json` — це ламає доставку оновлень на телефон.

## Mac — інструменти для збірки Android

- **Java:** `openjdk@17` через Homebrew (2026-09-08).
- **Android SDK:** `/opt/homebrew/share/android-commandlinetools`.
- **Змінні середовища** (`JAVA_HOME`, `ANDROID_HOME`, `ANDROID_SDK_ROOT`, `PATH`): у `~/.zprofile`.
- **Mac-застосунок mindEva:** збирається скриптом `scripts/build-mac.sh`, лежить у `desktop/release/mac-arm64/mindEva.app`.

## Ключі, що живуть тільки на телефоні

- **Pexels** (безкоштовні фото для фону плиток) — ключ введений у самому застосунку, зберігається лише на пристрої.
- **Gemini** — ключ лежить тільки на телефоні: Налаштування застосунку → розділ «Gemini» (у коді: `chat.geminiKey`).
  Створюється на aistudio.google.com/apikey. Тепер ним користуються: переклад статей у читачі, чат «Запитати»,
  і з 2026-10-15 — «Думки»: резюме, питання до вибраних карток, зміст відео YouTube, і голос (Gemini TTS).

## Телефон (Samsung Fold)

- **2026-10-15, ніч — нова збірка застосунку (APK) встановлена поверх старої.** Що нового в ній: модуль озвучування
  телефона (expo-speech) — запасний голос, коли Gemini недоступний. Через нову збірку змінився «відбиток» застосунку:
  оновлення по повітрю тепер доходять тільки до цієї збірки. Сама збірка: `scratchpad/apk/mindeva-thoughts-voice.apk`.
  Попередня (для повернення, якщо щось не так): копія лежить у робочій теці сесії, `installed/current.apk`.
  Озвучки Gemini зберігаються на телефоні в теці застосунку `thought-voice/`.

- **2026-10-15 — озвучування тексту.** Налаштування → Загальне керування → Перетворення тексту на мовлення →
  Пріоритетна система: **Google** (замість Samsung). Навіщо: у двигуні Samsung немає української.
  Встановлено український голос Google (працює офлайн, але монотонний).

## Заплановане, ще не налаштоване

- **ЗРОБЛЕНО 2026-10-15 вранці — платний рівень Gemini.** Передоплата (prepay): поповнення $5, автопоповнення
  увімкнене (коли залишок < $1 — докупити $5), місячний ліміт $6. Кредити тільки для Gemini API, не повертаються,
  згорають через рік від покупки. Змінити: aistudio.google.com → Billing (або Google Cloud Console → Billing).
  Перевірено на телефоні: питання й голос пройшли з першої спроби.
- (Як це робилось:) **Платний рівень Gemini (вранці 2026-10-15, картку прив'язує користувач).** Де: aistudio.google.com → API keys →
  у ключа є проєкт Google Cloud → «Set up billing» (прив'язати картку до цього проєкту). Навіщо: значно вищі
  ліміти запитів (на безкоштовному рівні голос і відео швидко впираються в ліміт), і Google НЕ використовує тексти
  для навчання (на безкоштовному — може). Після цього той самий ключ працює вже як платний, у застосунку нічого
  міняти не треба. Варто одразу поставити ліміт бюджету в Google Cloud → Billing → Budgets.

- **Google Cloud Text-to-Speech, голос Gemini 3.1 Flash TTS** — живе озвучування резюме.
  Оплата за фактом: близько 3 центів за хвилину звуку. Потрібні: акаунт Google Cloud з карткою,
  ліміт бюджету, увімкнена послуга Text-to-Speech, ключ. Файли озвучок зберігатимуться на телефоні.
- **Доступ до Claude (Anthropic API)** — якщо резюме писатиме Claude. Окрема оплата за фактом,
  не залежить від підписки Claude Pro/Max.
