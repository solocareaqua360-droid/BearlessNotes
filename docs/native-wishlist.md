# Список «потрібна нова збірка» (нативне)

Правило (узгоджено 2026-11-07): нативне не збираємо по одному, а складаємо сюди
і збираємо одним великим кроком на етап. Усе інше (екрани, вигляд, логіка) — OTA.

## Уже в збірці
- WebView-плеєр (YouTube/TikTok в застосунку), `react-native-webview`.
- Системне вікно «картинка в картинці» + кнопки −10 с / пауза / +10 с,
  вхід у вікно при виході із застосунку під час відтворення (`modules/cinema-native`).

## Перевірено на телефоні (2026-11-07, збірка №8, Claude через adb)
- Вихід у вікно: клавіша «Додому» і свайп знизу. Відео у вікні грає.
- Кнопки вікна (пауза, грати, ±10 с) і сповіщення (пауза, грати, +10 с) — працюють.
- Горизонтальне відео на весь екран, екран не гасне — перевірив користувач.
- НЕ перевірено: замкнений екран (потрібне розблокування обличчям/пальцем — тест лише коли користувач біля телефона).
- Уроки: (1) не давати Constant і Function одне ім'я в Expo-модулі — константа перекриває функцію; (2) `.gitignore` з `android/` ховає й `modules/*/android/`; (3) у вікні й на замкненому екрані команди в WebView через RN-міст не виконуються — тільки напряму (WebHost.eval); (4) на цьому Mac збірка на хотспоті вимагає `JAVA_TOOL_OPTIONS=-Djava.net.preferIPv6Addresses=true`; (5) діагностика сторінки плеєра: `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + CDP.

## Наступна велика збірка — вирішено «потрібно одразу» (користувач)
1. Горизонтальне відео на весь екран (`expo-screen-orientation`) + екран не гасне
   під час перегляду (`expo-keep-awake`).
2. Звук і керування із заблокованого екрана (сповіщення-плеєр, служба на передньому
   плані). **Спочатку перевірити**, чи звук грає при вимкненому екрані на поточній збірці.
6. Локальна база для бібліотеки (`expo-sqlite`) — офлайн-перший підхід.
7. Бекенд: ВИРІШЕНО — окремий новий Firebase для Cinema, веб-бібліотека (нативного не додає).

8. Косметика (узгоджено, кладемо в наступну збірку): у маленькому системному вікні
   сховати власну велику кнопку Play/Pause YouTube, бо вона видна під нашою (системною).
   Спосіб: нативний шматок підсовує CSS у iframe YouTube (`WebViewCompat.addDocumentStartJavaScript`
   для youtube-nocookie.com + повідомлення з батьківської сторінки «сховати/показати»).
   Копіювати вигляд кнопки не вийде: кнопки вікна малює система, не застосунок.
