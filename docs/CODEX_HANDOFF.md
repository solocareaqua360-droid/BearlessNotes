## 4. Витягти встановлений APK з телефона (рекомендовано зробити першим)
Потрібні кабель, USB-налагодження, `adb` (є в Android SDK). Телефон підключити, дозволити налагодження.
```
adb shell pm path com.bearlessnotes.notes
adb pull <шлях з першого рядка, без "package:"> ~/BearlessNotes-old/_apk-backup/phone-installed.apk
```
Якщо шляхів кілька (split-APK), витягни всі (`base.apk` та `split_*.apk`). Це точна копія того, що працює зараз. OTA-оновлення, що прийшли «по повітрю», лежать у даних
застосунку і в цей APK не входять; їхній код — це комміти гілки (розділ 1).
