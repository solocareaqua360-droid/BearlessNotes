# BearlessNotes — запуск застосунку на телефоні

Короткий гайд, як відкрити застосунок у Expo Go на своєму телефоні.
Все виконується на **вашому комп'ютері** (не в хмарі) — телефон і
комп'ютер мають "бачити" одне одного.

## 1. Встановіть Expo Go на телефон

- [Expo Go в App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)
- [Expo Go в Google Play (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)

## 2. Завантажте код на комп'ютер

Потрібен встановлений [Node.js](https://nodejs.org) (версія 18+) і git.

```bash
git clone https://github.com/solocareaqua360-droid/BearlessNotes.git
cd BearlessNotes
git checkout claude/video-bookmark-app-structure-4s4vfm
```

## 3. Встановіть залежності

```bash
npm install
```

Займе приблизно хвилину.

## 4. Запустіть застосунок

Якщо телефон і комп'ютер в одній Wi-Fi мережі (найпростіший варіант):

```bash
npx expo start
```

Якщо не в одній мережі, або Wi-Fi блокує з'єднання (буває в офісних/
корпоративних мережах) — використайте тунель:

```bash
npx expo start --tunnel
```

## 5. Відскануйте QR-код

У терміналі з'явиться QR-код.

- **iPhone**: відскануйте його звичайною камерою — з'явиться підказка
  відкрити в Expo Go.
- **Android**: відкрийте застосунок Expo Go і натисніть
  "Scan QR code" прямо в ньому.

Застосунок завантажиться і відкриється на телефоні. Поки термінал з
`npx expo start` запущено на комп'ютері — можна редагувати код, і
зміни одразу з'являтимуться на телефоні.

## Якщо щось не працює

- **QR-код не сканується / "не вдалось підключитись"** → спробуйте
  `npx expo start --tunnel` замість звичайного `npx expo start`.
- **`npm install` видає помилки** → перевірте версію Node.js:
  `node -v` має показати 18 або новіше.
- **Тунель довго "висить" і не з'єднується** → перезапустіть команду,
  іноді допомагає з другої спроби; або перевірте, що антивірус/VPN не
  блокує з'єднання.
